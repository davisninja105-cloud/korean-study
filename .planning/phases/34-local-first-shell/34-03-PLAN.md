<objective>
Make `/cards` local-first without changing what it loads. The card list paints the
session-accumulated groups from IndexedDB before `GET /api/cards` answers, revalidates only
when `/api/version` moves, and every edit, delete, and add patches the cached entry in the
same handler that already patches component state.

Purpose: `PUT /api/cards/[id]` does NOT bump the server version counter (verified in
34-RESEARCH.md Pitfall 3 against `lib/settings.ts`'s own doc comment). Version-check
revalidation therefore can never correct a card edit in the cache — write-through is not an
optimisation here, it is the only mechanism that keeps `/cards` honest.

Output: a cache-first `components/CardsClient.tsx` with write-through at all three mutation
sites, a D-05-scoped `handleRefresh`, and a Playwright spec proving the pre-edit value can
never come back.
</objective>
